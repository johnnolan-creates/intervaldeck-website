# Security Policy

## Scope

This repository hosts the static promotional website and privacy policy for **IntervalDeck — Flow Timers**.

## Reporting a Vulnerability

If you discover a security vulnerability, misconfiguration (such as domain, DNS, HTTPS, or `app-ads.txt` issues), or a security concern within the **IntervalDeck** Android application, please do **not** open a public GitHub Issue.

Instead, report it privately via one of the following methods:

1. **GitHub Private Vulnerability Reporting:** Use the **Security > Advisories > Report a vulnerability** button in this repository.
2. **Email:** Send details to **[intervaldeck@gmail.com]** with the subject line `[Security] IntervalDeck`.

Please include:
- A clear description of the issue and potential impact.
- Steps to reproduce or relevant URLs/screenshots.

You can expect an acknowledgment within **72 hours**, and updates as the issue is investigated and resolved.
